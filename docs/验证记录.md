# Validation record — 0.1.2-alpha

The full platform remains NOT_READY. These are maintenance checks for the CLI alpha and independent Native prototype, executed on 2026-10-23 (Asia/Shanghai).

## Current upgrade

- H1 headings, including title-only and consecutive H1 sections, remain visible. A table separator is consumed only immediately after its header; later `---` cells remain data.
- The legacy compiler delegates to the canonical compiler. Input aliases and existing outputs/reports are rejected. XML-forbidden characters in table cells, headers and other rendered text fail before PPTX publication; valid supplementary Unicode is allowed.
- Native jobs preflight paths before Office activation. PDF publication refuses overwrite, including a destination created during export. Evidence directories reject path traversal and linked parents. Runtime launch failures, malformed JSON, timeouts, PID reuse and forced cleanup have regressions. Native readback compares slide/shape/text boundaries, retaining whitespace.
- `image-size` is pinned to 2.0.4 for PptxGenJS's unused dependency; the published 3.12.0 JavaScript entries were inspected. Pillow is pinned to 13.0.0. NuGet test dependencies were updated within their existing major versions. Six official GitHub Actions were checked and pinned to Node 24 runtime commits.

## Current real artifacts and Office checks

The canonical sample compiles to seven slides with deterministic QA score 97. The former five-slide output omitted the two H1 headings; both are now visible title pages. A separate PNG fixture made with Pillow 13 is embedded in a real PPTX and inspected after native export. Slide XML was read back in the CLI regressions.

On PowerPoint 16.0, both the seven-slide sample and the image fixture completed open, copy save, close, reopen, text edit/save/reopen/restore, ordered text readback, PDF export, all slide PNG exports, sampled modal checks, font-name reads and Quit. Both returned exit 0 with no fatal diagnostic, forced cleanup or remaining task-owned PowerPoint process. The protocol worker separately exported the seven-slide PDF through its new temporary-publication path. Same-path, existing-output and missing-input requests failed while preserving source and sentinel bytes.

Complete OpenXML schema certification, font substitution, visual fidelity, malformed-file recovery and the desktop/installer/clean-machine gates remain unverified. Native `is_release_ready` remains false.
