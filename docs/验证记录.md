## Actual Office probe

PowerPoint 16.0 was exercised on the five-slide CLI output. The .NET child performed original open, copy save, close, reopen, text edit, save, close, reopen and restore, semantic readback, native PDF, five slide PNG exports, sampled modal-dialog checks, close and Quit. The parent recorded exit 0, no fatal diagnostic and no remaining task-owned PowerPoint process.

The former Python COM path reproduced `0x80010108` during proxy release even after operations completed. Its failure logs were retained. Native work now runs in a separate .NET Worker without Python COM proxies. The .NET path was tested separately; this does not establish correctness for every Office version, malformed file or cancellation timing.

OpenXML schema certification, font substitution and visual fidelity are still unverified. The probe therefore reports partial Native tiers and `is_release_ready=false`. Successful PDF/PNG generation is not visual acceptance.
