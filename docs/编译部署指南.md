# 编译部署指南.md — PresentationOS 新机器从零搭建唯一指南

> 版本：0.0.0（2026-09-21，PHASE 0 实测）
> 规则：所有命令必须真实执行过；记录工作目录/命令/exit code/预期结果/失败处理。

## 1. 支持 OS
Windows 11（当前实测环境：Windows 11 Home China Build 26200，x64）。

## 2. CPU / RAM / GPU 建议
- 开发：i5 或以上，16GB RAM。
- 本地模型（可选）：显存 ≥ 4GB（RTX 3050 Laptop 4GB 实测可用 Q4 量化小模型）；16GB 以上更佳。

## 3. Node
- 实测：v22.23.2（`node --version`）。要求 ≥ 20。
- 安装：官网 LTS 安装包，或 winget install OpenJS.NodeJS.LTS。

## 4. pnpm
- 实测：12.5.1。安装方式（实测通过）：
  ```powershell
  corepack enable
  corepack prepare pnpm@latest --activate
  pnpm --version   # → 12.5.1
  ```

## 5. Rust
- 实测：rustc/cargo 1.98.1（stable-minimal）。
- 安装（实测通过，需代理）：
  ```powershell
  $env:HTTPS_PROXY="http://127.0.0.1:7897"; $env:HTTP_PROXY="http://127.0.0.1:7897"
  Invoke-WebRequest -Uri "https://static.rust-lang.org/rustup/dist/x86_64-pc-windows-msvc/rustup-init.exe" -OutFile "$env:TEMP\rustup-init.exe"
  & "$env:TEMP\rustup-init.exe" -y --default-toolchain stable --profile minimal
  # rustc 安装到 %USERPROFILE%\.cargo\bin（重启 shell 生效）
  ```

## 6. Tauri 2
- 前置：Rust + WebView2（Win11 自带）+ Node。
- 待 PHASE 17 安装（`pnpm create tauri-app`），此处留位。

## 7. .NET
- 实测：.NET SDK 8.0.425。
- 安装（实测通过，需代理）：
  ```powershell
  $env:HTTPS_PROXY="http://127.0.0.1:7897"; $env:HTTP_PROXY="http://127.0.0.1:7897"
  Invoke-WebRequest -Uri "https://dot.net/v1/dotnet-install.ps1" -OutFile "$env:TEMP\dotnet-install.ps1"
  & "$env:TEMP\dotnet-install.ps1" -Channel 8.0 -InstallDir "$env:LOCALAPPDATA\Microsoft\dotnet"
  # dotnet 在 %LOCALAPPDATA%\Microsoft\dotnet\dotnet.exe
  ```
