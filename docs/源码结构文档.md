## 2. 每个顶级目录职责

| 目录 | 职责 |
|---|---|
| apps/ | 面向用户的入口（Desktop/CLI/API），不持有核心业务逻辑 |
| kernel/ | 平台内核：Capability/Workflow/Artifact/Worker 管理/模型路由/遥测/溯源 |
| schemas/ | 平台自有稳定数据协议（JSON Schema 2020-12），所有 IR 与协议的唯一权威 |
| workers/ | 各运行时执行进程，遵守 Worker Protocol (pres-worker/1) |
| capabilities/ | 能力实现域（source/research/narrative/design/layout/render/pptx/qa/speech/video…） |
| providers/ | 可替换实现提供方（模型/渲染器/模板/风格/QA 引擎） |
| adapters/ | 第三方引擎适配（PptxGenJS/python-pptx/OOXML/PowerPoint COM/Browser/LibreOffice/FFmpeg） |
| upstream/ | H:\ppt 上游项目 manifests 与 audits（机器可查） |
| tests/ | 全层级测试 |
| tools/ | 工程工具（auditor/gui-automation/docs-auditor） |
| state/ | 机器可读项目状态 |
| evidence/ | 每个功能一个 Evidence Pack |
| docs/ | 五个专项 MD |
| bugs/ | Bug 文档（BUG-xxxx.md） |
