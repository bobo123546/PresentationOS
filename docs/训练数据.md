## Case 记录字段（每条 Case 必须包含）

| 字段 | 说明 |
|---|---|
| case_id | 唯一 ID（如 GOLD-0001） |
| case_type | 商务汇报 / 咨询 / 学术 / 营销 / 课程 / 数据分析 / TemplateDNA / ExistingPPT / ScreenshotRecon / Skill / GUI / WorkflowRecovery / PowerPointNative / VisualQA |
| source | 来源（人工构造 / 真实案例 / 上游项目 / 用户素材） |
| input | 输入摘要（避免完整敏感内容） |
| expected | 期望结果（结构化） |
| actual | 实际结果（结构化） |
| model | 模型名称 |
| model_version | 模型版本 |
| prompt_version | Prompt 版本 |
| workflow_version | Workflow 版本 |
| capability_version | Capability 版本 |
| runtime | 运行环境 |
| duration | 耗时 ms |
| cost/tokens | 成本/Token（如适用） |
| qa_result | QA 结果（PASS/FAIL + 指标） |
| human_result | 人工评估（如适用） |
| failure_cause | 失败原因 |
| golden_status | GOLDEN / REGRESSION / EXPERIMENT / SUPERSEDED |
