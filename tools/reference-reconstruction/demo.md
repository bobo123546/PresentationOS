# AI 内容工厂

## 市场背景

> 生成式 AI 正重塑内容生产全链路

- 文本、图像、音频、视频四类内容可自动生成
- 企业内容成本下降 60%+
- 交付周期从周级压缩到小时级

## 产品定位

- 面向中小企业的 AI 内容中台
- 一键生成营销物料
- 全链路可编辑、可审核

## 技术架构

| 层 | 技术 | 说明 |
|---|---|---|
| 模型层 | Qwen / FLUX / CosyVoice | 多模态生成 |
| 平台层 | Worker / Capability | 能力编排 |
| 应用层 | Desktop / CLI / API | 多入口 |

## 核心能力

1. 文案生成与多平台改写
2. 配图与视觉风格统一
3. 配音与视频合成
4. 人工审核与一键发布
